Privacy Policy

YouTube Floating Lyrics is designed to display lyrics for YouTube videos in a floating overlay and optional Picture-in-Picture window.

Data Collection and Use

  • The extension reads limited information from the current YouTube page, such as the video title and channel name, to identify the current song.
  • The extension may send song-related information to an external lyrics provider in order to retrieve lyrics.
  • The extension stores user preferences locally, such as font settings, text size, widget position, and other display options.

The extension does not collect personally identifiable information such as name, email address, password, or payment information.

Data Sharing

  • The extension does not sell user data.
  • The extension does not use user data for advertising purposes.
  • The extension does not transfer user data to third parties except as necessary to retrieve lyrics from the lyrics provider.

Remote Code

The extension does not execute remote JavaScript or WebAssembly code.
